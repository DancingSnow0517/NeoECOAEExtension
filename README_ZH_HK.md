## 概述

Neo Eco AE Extension是[Eco AE Extension](https://github.com/sddsd2332/NovaEngineering-ECOAEExtension)的高版本移植, 添加了來自[新星工程：世界](https://www.mcmod.cn/modpack/784.html)中的 MMCE 多方塊結構。在獲得原作者授權的前提下，本項目以 GNU 通用公共許可證第3版（GPLv3）發布。

## Neo Eco AE Extension提供了什麼?

Neo Eco AE Extension為 Applied Energistics 2引入了三種大型核心組件，將合成、存儲與計算拆分為三個獨立的多方塊結構。每種結構均包含三個等級，每一等級都相比前一級帶來顯著的性能提升。

此外，本模組還提供了一系列高性能組件，大幅提升自動化系統的易用性與操作舒適度，讓你的自動化之旅如同呼吸一般簡單。 ~~核電，輕而易舉啊~~

## 重要提示

Neo Eco AE Extension與Eco AE Extension之間僅存在經授權的移植關係，兩者在項目層面不存在任何直接的隸屬關係或依賴關係。
兩個項目均由不同的開發團隊獨立維護與開發。

請不要將有關Neo Eco AE Extension的問題、Bug報告或技術支持請求提交至Eco AE Extension項目，否則相關問題將無法得到有效處理，並可能對Eco AE Extension團隊的維護與開發工作造成不必要的干擾。
