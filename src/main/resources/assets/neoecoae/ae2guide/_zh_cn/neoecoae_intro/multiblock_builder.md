# 多方块自动搭建

控制器提供结构预览与自动搭建功能。

支持[存储](storage_system.md)、[计算](computation_system.md)与[合成](crafting_system.md)系统。

## 搭建操作

通过控制器侧边按钮打开搭建面板，选择结构长度。

点击“预览”检查材料和结构，点击“搭建”开始施工。

调整控制器朝向或结构长度后需重新预览。

## 结构预览

| 预览项目 | 含义 |
|----------|------|
| 缺失方块 | 待放置的结构方块 |
| 冲突方块 | 需要清理的已有方块 |
| 可复用方块 | 可保留的结构方块 |
| 所需物品 | 搭建所需材料数量 |

有效结构方块可复用，冲突方块需先清理。

## 材料消耗

材料来自玩家物品栏及支持的潜影盒、背包等容器。

生存模式按放置数量消耗材料；创造模式无需材料。

## 搭建中断

材料不足或目标位置冲突时，搭建会中断。

处理后重新预览，点击“搭建”继续。


## JEI / EMI 结构预览

预览支持分层、长度和成型外观切换。

循环选项：左键下一项，右键上一项。
