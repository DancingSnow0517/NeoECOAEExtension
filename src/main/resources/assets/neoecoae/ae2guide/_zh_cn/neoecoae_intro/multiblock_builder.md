# 多方块自动搭建

搭建 [ECO 存储系统](storage_system.md)、[ECO 计算系统](computation_system.md)和 [ECO 合成系统](crafting_system.md)时，空手右键对应主机，使用主机 UI 内的搭建按钮。各系统的 L4/L6/L9 均使用自己的主机界面。

## 选择长度并开始搭建

放置主机并确认朝向后，点击主机界面的搭建按钮，打开搭建设置子窗口。窗口固定四行：长度文字、长度输入、长度调整，以及镜像开关与开始搭建按钮。可以直接输入长度，也可以用 −10、−1、+1、+10 按钮调整；输入框会提示允许的长度范围。

确认长度、镜像方向和材料后，点击开始搭建。右上角返回按钮关闭子窗口并保留当前设置。主机已经成型或正在搭建时，设置与开始按钮不可用。

## 材料与搭建过程

将材料准备在玩家当前可访问的物品中。系统也能识别提供物品处理能力的容器物品，例如符合这一条件的潜影盒、背包和其他容器。

生存模式会按服务器 tick 逐步放置方块，每次成功放置时才消耗对应物品，开始前不会一次扣除全部材料。创造模式下，只要没有冲突，就会立即补齐全部缺失方块。

自动搭建不会直接覆盖冲突方块。材料不足、目标位置被阻塞或存在冲突，都可能使搭建无法开始或中途停止。补足材料、清理目标位置后，回到对应主机的搭建窗口重试。
