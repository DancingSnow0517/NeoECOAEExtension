# Bundled UI textures

The files under `ae2/` are unmodified copies from Applied Energistics 2,
`AppliedEnergistics/Applied-Energistics-2`, branch `1.21.1`, commit `fd8b717a4`.
The source paths are `src/main/resources/assets/ae2/textures/guis/` and
`src/main/resources/assets/ae2/textures/gui/sprites/`. They are distributed
under the GNU Lesser General Public License v3; see `ae2/LICENSE-AE2.txt`.

The file `ldlib/gdp_styles.png` is an unmodified copy from LDLib2,
`Low-Drag-MC/LDLib2`, branch `1.21`, commit `7ecdb255`.
Its source path is `src/main/resources/assets/ldlib2/textures/gui/gdp_styles.png`.
It is distributed under the GNU Lesser General Public License v3; see
`ldlib/LICENSE-LDLib2.txt`.

These local copies keep this mod's UI artwork stable when dependency texture
paths or atlas coordinates change.
