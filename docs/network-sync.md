# 网络同步优化与验证

本次修改面向 Minecraft 1.21.1、NeoForge 21.1.233、AE2 19.2.17、LDLib2 2.2.8。
自定义 Payload 协议为 `3`（样板预览紧凑分页协议）；客户端和服务端必须同时更新。

## 数据路径

| 数据 | 修改后的同步方式 |
| --- | --- |
| 终端精确数量 | 首次全量，随后发送新增、修改和删除项；最短采样间隔 5 tick；传输未结束时不重复收集 |
| CPU stored/active/pending 精确数量 | 三张表在同一个消息内原子更新；按条目增量；CPU 切换取消旧传输并建立完整基线 |
| CPU 精确预览构造 | 同一 CPU 的多个查看者共享短期采样缓存；缓存使用弱引用，服务器停止时清理 |
| 合成图与循环条目 | 同一消息分片；保留图压缩，减少未压缩数据的一次完整复制；版本变化取消旧传输 |
| 样板预览 | 菜单范围推送；共享脏槽编码缓存，每位查看者仅保存待更新槽位；256 个物理槽位一页，连续空槽压缩、重复内容去重、磁盘配方增量；完整接收后提交 |
| 大订单进度 | 二进制大整数；普通数量变化最短间隔 5 tick；订单、CPU 或状态变化立即同步 |
| 普通开始/强制开始 | 一个 C2S 意图包包含菜单 ID 和强制标志；服务端校验菜单及有效性后，在同一主线程任务中设置标志并提交 |
| 主机任务列表 | 保留原有任务增量及条目预算；顺序不变时不再附带完整顺序列表 |
| 界面计数与性能 | 移除仅由菜单使用的重复方块描述同步；传输量采样；进度条取百分比精度；性能标题和提示共用一个微秒精度数值 |

AE2 普通合成状态继续使用其已有的 `IncrementalUpdateHelper`。世界渲染字段、真实库存、存档数据和初始区块同步桥接保持原有语义。

## 分片与预算

`MenuDataTransport` 管理 TERMINAL、CPU、GRAPH、PATTERNS 四个批量通道。

- 每片数据体最多 16 KiB。
- 每位玩家每个服务器 tick 的共享预算为 34 KiB；每片在预算中另计 128 字节的保守封装开销。
- 通道采用轮转发送；每个菜单/通道最多保留一个在途消息，不积累每 tick 的历史快照。
- 单个重组消息最多 32 MiB。图自身另有 16 MiB 压缩、64 MiB 解压限制。
- 重组要求消息 ID、总长度和偏移连续一致；接收完成后才提交数据。
- 服务端菜单实例改变或玩家断开时丢弃待发数据；客户端每 tick 清理已关闭菜单的重组缓冲。
- CPU 或规划结果切换允许取消旧消息，下一条消息的首片重置接收缓冲。

该预算只约束这四个批量通道，不代表限制了 Minecraft 全部流量，也不包括 AE2 原有小包、LDLib 其他绑定以及任务生命周期通知。
任务列表原有 24,000 预算依然是其条目估算预算，不应解释为全连接或外层包的严格上限。

5 tick 在 20 TPS 下为 250 ms；服务器低 TPS 时实际显示延迟会增加。大快照的接收时间还受其大小和共享预算影响。

## 正确性约束

精确数量的删除项必须显式发送，零、无限和不存在不能混淆。有限值统一按非负 BigInteger 二进制传输。
菜单关闭后必须重新建立基线，不能在新菜单上沿用旧增量。

合成图还用于确认页的精确材料表，不能仅在打开图页面后获取。确认页通过诊断版本匹配判断数据是否完整；加载过程中显示提示并禁用提交，避免旧图与新规划结果混用。

样板预览在完整快照发送期间仍维护最新缓存，但不会不断重启该传输。发送完成后，以刚才的快照为基线发送后续差异。目录版本用于同步基线；操作校验菜单、物理位置及客户端实际看到的目标物品，避免无关槽位变化使点击失效。详细设计及回归见 [样板预览重构](pattern-preview.md)。

## 观测与回归

管理员命令：`/neoecoae network_report`。

输出四个批量通道自服务器启动以来的消息数、分片数、编码数据体字节数、累计编码耗时，以及单玩家单 tick 预算峰值和当前排队玩家数。
统计字节数位于 Minecraft 传输压缩之前；GRAPH 内部已经压缩。编码耗时不包括调用方的库存枚举或规划计算。
可对固定时间窗口前后的计数作差；不要将这些数值当作实际网卡流量或整个服务器的包数。

建议在相同存档、玩家数、TPS 和观察时长下对比：

1. 大型精确库存静止、单条持续变化、多条变化与删除。
2. 多玩家查看同一 CPU，执行超大订单并切换 CPU、取消订单。
3. 大型样板目录首次打开、传输期间修改目录、关闭再打开和重发。
4. 大型合成图，以及传输中更换规划结果。
5. 无玩家打开面板时，接口传输与样板迁移仍正常运行。

自动验证：`./gradlew.bat build --console=plain`。
本轮构建报告 283 项测试：281 项通过、2 项跳过、0 失败；其中新增 12 项网络测试覆盖预算、取消、重组、增量删除、大整数、持续变化预览、图编码及单包提交校验。

本轮没有运行多人实服流量基准，因此不报告实际带宽降幅或客户端帧时间改善百分比。
