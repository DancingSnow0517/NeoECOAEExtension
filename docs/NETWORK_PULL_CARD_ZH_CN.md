# 流体输入仓网络拉取卡

参照 GTM 的 ME 输入仓：标记流体和目标库存分开保存，每 20 tick 退回旧液/超额部分，再补足目标缺口。

未安装卡片时保留原流体输入仓界面和 16000 mB 的普通输入容量，只在右侧增加一个升级卡槽。安装网络拉取卡后，界面立即显示流体标记、目标库存与真实缓存；卸下卡片后立即恢复旧布局。切换时使用同一套背包和升级槽，菜单槽号保持稳定。

装卡后的背景直接使用用户提供的原始 PNG，按 176×159 有效区域原尺寸绘制。中央上槽用于标记冷却液及显示目标数量，下槽用于显示、取用真实缓存。标记使用 AE2 的 CONFIG_STACKS/FakeSlot 规则：容器右键标记内部流体，空手左键清除；包装流体左键增加、右键减少。齿轮仅在已标记时显示，点击后使用桶（B）输入目标量，支持小数及 ±1/10/100/1000 桶按钮，按“设置”确认；设为 0 清除标记。

网络模式的真实缓存以长整型 mB 数量保存，不受原有 16 桶限制。槽内数量复用 AE2 的 AmountFormat.SLOT 与 StackSizeRenderer；悬浮数量复用 AmountFormat.FULL，按桶显示，例如 2500 mB 显示为 2.5 B，300000 mB 的槽内显示为 300。底层数量范围仍为 0～Long.MAX_VALUE mB。网络拒收的超额或旧流体会保留并重试，不会直接删除；抽取遵循 AE2 的供电检查。

卸卡时已有的大容量缓存继续保留并可被冷却系统消耗，普通输入在缓存降至 16 桶以下后恢复接收。标记、目标、真实库存和卡槽均持久化。旧存档从原流体数量迁移，缺少目标字段时默认 16000 mB。

配方：4 个铝合金锭、2 个无线接收器、1 个奇点、1 张高级卡、1 个超导处理器，合成 1 张卡。卡片使用用户提供的 16×16 原始 PNG，文件未经重新绘制。
