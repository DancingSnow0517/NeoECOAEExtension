# 合成子系统通讯接口样板预览重构

## 参考与行为

参考 ExtendedAE 1.21.1-neoforge 的 `ContainerAssemblerMatrix`、`GuiAssemblerMatrix`（`6cf9c0b`），以及 AE2LT Reborn 的 `MatrixPortMenu`、`MatrixPortScreen`（`a98e2a3`）。采用物理行布局、客户端搜索和固定可见窗口；没有引入对参考项目的新运行时依赖。

- 搜索保留命中样板所在的整行，匹配项高亮，其余项变暗。行不会跨越样板总线边界。
- 客户端缓存本地语言的输入、输出搜索词，保留服务端词作为兼容回退。右键清空搜索，滚轮及拖动滚动条浏览。
- 支持隐藏空行、物品替代与流体替代筛选；显示加载状态和行范围。
- 悬停显示来源坐标及物理槽位。磁盘图标不携带完整内嵌数据，盘内配方单独显示为只读行。
- 辅助存储 API 提供的是总线级配方集合，因此只在第一个磁盘槽位附带一次；避免多个磁盘重复显示整个总线的配方。
- 普通样板保留点击、Shift 点击、Shift 拖动批量取回及从背包快速放入操作。服务端逐目标验证物品快照，保持磁盘只读和迁移期间的操作锁。
- 迁移结果中的“不兼容”改为“非合成样板”，英文和现有繁体文案同步更新。

## 同步与开销

`PatternPreviewSync` 缓存每个物理槽位的不可变编码内容。槽位通知只设置脏位；一次变化只编码一次，多人共享结果。每位查看者保存待发送的脏位及磁盘基线，不再每 5 tick 比较整个目录。

初始化和变化构造采用每 tick 最多 256 个物理槽位、约 2 ms 的协作式时间预算；至少处理 16 槽以保证推进。轮转游标避免目录前部持续变化饿死后部；完整初始化后即使仍有脏位，也会发布已处理的增量。单次第三方库存或磁盘 API 调用不能被该软预算中断。

物理槽位每 256 项一页，保持既有 `MenuDataTransport` 的每玩家每 tick 34 KiB 共享传输预算。客户端在整个逻辑快照结束后一次提交。页内连续同内容槽位按范围编码，重复内容共享字典；磁盘后续更新只发送变动的配方索引和新的配方总数。单个磁盘首次内容仍受既有 32 MiB 消息上限约束。

协议版本升为 3。客户端和服务端需要使用同一构建。此变更不修改存档格式。

编码回归样例：256 个连续空槽，原 NBT 数据体 23,898 字节，新编码 25 字节；不含外层包头，也不代表真实服务器的整体带宽降幅。可使用 `/neoecoae network_report` 对照实际 PATTERNS 通道流量。

## 网络扫描

先检查上次发现合成样板的槽位，再按历史命中容器、装配矩阵/样板核心/样板存储/分子装配室、样板提供器、其他 `PatternContainer` 的顺序覆盖其余槽位。类型名称仅作可选模组提示，未知类型不会被漏掉。热槽位阶段跨越整个网络，避免大容器空容量阻塞其他已知样板。

扫描保留每 tick 2 ms 和 1024 次实际槽位读取的限制。候选按发现顺序进入队列，每批领取不再构造全部候选，也不再从目录起点重复查找。认领仍具备互斥、释放、失效和超时回收语义。

## 验证

`gradlew.bat build --console=plain` 包含编译、全部单元测试及 JAR 构建。新增回归覆盖物理行保持、搜索与替代筛选、磁盘只读行、空槽编码、稀疏编码、输入边界、分页中的修改、持续变化下初始化、同大小拓扑重置、重新打开菜单、多人共享编码、磁盘增量、扫描优先级、热槽位及候选互斥。

尚未进行游戏内视觉验收或多人实服性能基准。游戏内应验证中文输入、鼠标拖动、Shift 批量操作、不同 GUI 缩放、多个磁盘和网络增删总线，并核对物品数量守恒。
