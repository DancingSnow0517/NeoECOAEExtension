## 中文

Minecraft 1.20.1 / Forge，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。

### 新增与优化

- 支持通过存储接口批量转入 GTL 无限存储盘，保留精确数量、资源过滤与迁移恢复。
- 优化存储读写、落盘调度、网络增量更新、终端库存快照和接口搬运，减少重复遍历与临时对象。
- 使用分段计数处理超大库存，保留规划中的精确数量与无限库存语义。
- 优化无环规划的路线重试，复用有效计算前缀、活动图检查和配方数量展开。
- 优化加工状态首屏与增量同步，关闭状态页后停止后台请求。
- 完善合成报告统计与材料卡片，支持 Shift 查看精确数量和流体单位换算，提前同步最终方案摘要。

### 修复

- 修复原版 CPU 与 ECO 互切时的状态和监听器清理，并保护异常状态条目的显示。
- 修复请求器循环订单接入 ECO 规划及已就绪节点重复初始化的问题。
- 修复正式环境下终端大数量库存差异注入的问题。
- 兼容 GTL 库存快照实现，保留其原有存储更新流程。
- 将机壳碰撞箱调整为完整方块。
- 为四种充能水晶母岩补齐 AE2 生长加速标签。

### 兼容性说明

- 请同步升级客户端和服务端。

## English

Minecraft 1.20.1 / Forge. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**.

### Added and improved

- Added bulk imports from GTL infinite storage cells through storage interfaces, preserving exact quantities, resource filters, and migration recovery.
- Optimized storage access, save scheduling, incremental network updates, terminal inventory snapshots, and interface transfers to reduce repeated scans and temporary allocations.
- Added segmented counting for very large inventories while preserving exact quantities and infinite-stock semantics during planning.
- Optimized acyclic route retries by reusing valid calculation prefixes, active graph checks, and recipe quantity expansion.
- Improved initial and incremental processing status synchronization and stopped background requests when the status screen closes.
- Improved crafting report statistics and material cards, including Shift tooltips for exact quantities, fluid unit conversion, and earlier final-plan summaries.

### Fixed

- Fixed status and listener cleanup when switching between vanilla CPUs and ECO, and guarded rendering of invalid status entries.
- Fixed requester loop orders using ECO planning and repeated initialization of ready nodes.
- Fixed large-quantity terminal inventory delta injection in production environments.
- Preserved the original storage update flow when GTL inventory snapshots are present.
- Changed casing collision shapes to full blocks.
- Added the AE2 growth acceleration tag to all four energized crystal budding blocks.

### Compatibility

- Update both client and server together.
