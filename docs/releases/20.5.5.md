## 中文

Minecraft 1.20.1 / Forge，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。

### 新增与优化

- 新增统一的 ECO 合成状态页，支持 CPU 分页、任务排序、滚动与搜索，并可定位加工机器及样板供应器。
- 重做智能冷却面板、主机状态提示和循环规划图，统一温度、并行、容量及大数量显示；支持按住 Shift 查看 CPU 精确统计。
- 新增网络共享的智能翻倍开关与状态卡片；关闭后按 CPU 实际并行数限制单次发配，同一 ME 网络的计算主机共享设置。
- 完善大型集成工作站的升级模块预览、中英文图文指南和 GuideME 配方展示，优化配方索引、匹配与发配缓存。
- 优化普通合成路线、副产物共享、自增殖循环及批量发配，减少重复规划、样板匹配和网络刷新；CPU 待合成数量改为一次汇总。
- 优化无限存储域与存储盘的资源读写、精确数量记账和列表缓存；终端共享网络库存快照并按变化资源更新，减少重复查询与临时对象分配。
- 补齐 GT 材料加工、充能水晶粉、充能福鲁伊克斯水晶粉及超导处理器配方，兼容旧版与新版 GT 配方格式。
- 增加开发环境随机资源发生器、网络写入采样与 key 工厂对照工具，便于分析存储网络负载。

### 修复

- 修复 JEI 初始化多方块配方时生成最大长度虚拟结构导致内存耗尽的问题；JEI / EMI 材料统计不再创建虚拟世界或保存全部方块位置。
- 修复循环合成的保种、副产物生产路线和材料平衡判断；优先保留首个可完成的普通路线，材料不足时再搜索备用组合，关闭循环规划时也可回退。
- 修复跨循环共享无限输入、大数累计预留及启动恢复需求溢出的规划与诊断问题，补齐精确订单合成图中的缺料节点。
- 修复智能翻倍样板跨实例匹配失败导致批量发配退化的问题，并对 AE2 网络重算进行拓扑校验与重复刷新合并。
- 修复大型工作站流体自动导出回填、空流体数量复制，以及过热时未显示待发任务和阻塞原因的问题。
- 修复无限基础资源盘和无限沙子盘在图标、提示、升级库存等只读查询中产生额外 NBT，导致合成样板资源匹配变化、任务无法结束的问题。
- 修复存储盘类型灯与等级灯的共面闪烁、客户端窗口缺失时的 Shift 状态读取异常，以及界面动态布局后的尺寸与缩放计算。
- 修正合成状态整格进度、短周期同步计数、控制器与工作站标题、悬停提示及多语言词条；补齐盈能水晶母岩的 Forge 通用芽块标签。

### 内容调整

- 智能冷却模块支持手动标记冷却液，切换冷却液前会先将旧库存退回 ME 网络。
- 移除已停用的普通大宗盘外壳配方，避免与流体外壳配方冲突。
- 多方块视觉预览最多显示 32 段扩展（总长度 36）；实际结构检查和自动搭建仍遵循服务器配置上限。
- 交换网络与无限模式批次统一按 1 tick 执行，同步工作核心、控制器耗时显示及指南。
- AE 资源 key 复用限定于 ECO 自有工厂，保留 AE2、Applied Flux 公共工厂行为及旧存档兼容性。
- 若旧样板已记录无限资源盘的异常 NBT，请重新编码；已挂起的任务需取消后重新下单。
- 客户端与服务端请同步更新，升级前请备份存档。

## English

Minecraft 1.20.1 / Forge. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**.

### Added and improved

- Added a unified ECO crafting status screen with CPU pagination, task ordering, scrolling, and search, plus links to processing machines and pattern providers.
- Reworked cooling panels, host status tooltips, and cycle graphs, with consistent temperature, parallelism, capacity, and large-number displays. Hold Shift for exact CPU statistics.
- Added a network-wide smart-doubling toggle and status card. Disabling it limits each dispatch by actual CPU parallelism, with settings shared across computation hosts on the same ME network.
- Improved Large Integrated Workstation upgrade previews, illustrated Chinese and English guides, and GuideME recipe displays, plus recipe indexing, matching, and dispatch caches.
- Improved ordinary routes, shared byproducts, self-growing cycles, and batch dispatch while reducing repeated planning, pattern matching, and network refreshes. Pending CPU outputs are aggregated in one pass.
- Improved Infinite Storage Domain and storage-cell access, exact accounting, and list caching. Terminals share network snapshots and update changed resources, reducing repeated queries and temporary allocations.
- Completed GT material processing, energized crystal dust, energized fluix crystal dust, and superconducting processor recipes for both older and newer GT recipe formats.
- Added development-only random resource generators, network write profiling, and key factory comparison tools for investigating storage network load.

### Fixed

- Fixed memory exhaustion when JEI generated maximum-length virtual structures during multiblock recipe registration. JEI / EMI material collection no longer creates a dummy world or retains every block position.
- Fixed seed preservation, byproduct production routes, and material balance checks in cycle crafting. Preserve the first viable ordinary route and search alternatives only when supplies are insufficient, including when cycle planning is disabled.
- Fixed planning and diagnostics for shared infinite inputs, large accumulated reservations, and overflowing startup recovery requirements. Added missing ingredient nodes to exact-order crafting graphs.
- Fixed cross-instance matching of smart-doubling patterns degrading batch dispatch, and added topology validation and refresh deduplication for AE2 network recalculation.
- Fixed workstation fluid auto-export remainders, copying quantities from empty fluids, and missing pending tasks or blocking reasons when workstations overheat.
- Fixed read-only icon, tooltip, and upgrade-inventory queries adding NBT to Infinite Basic Resource Cells and Infinite Sand Cells, changing encoded resource identities and preventing crafting jobs from finishing.
- Fixed flickering between storage-cell type and tier lights, Shift-state access without a client window, and size or scaling calculations after dynamic UI layout changes.
- Corrected whole-operation crafting progress, transient synchronization counts, controller and workstation titles, tooltips, and translations. Added the common Forge budding-block tag to Energized Crystal Mother Rock.

### Content changes

- Smart cooling modules support manually marked coolant, returning old coolant to ME storage before switching types.
- Removed the retired standard bulk-cell housing recipe to avoid a conflict with fluid housing.
- Visual multiblock previews are limited to 32 repeating sections, or 36 blocks total. Real structure validation and automatic building still follow server-configured limits.
- Exchange-network and unlimited-mode batches now execute in one tick, with matching worker and controller timing displays and updated guides.
- AE resource key reuse is limited to ECO-owned factories, preserving native AE2 and Applied Flux public factory behavior and existing save compatibility.
- Re-encode old patterns containing the affected infinite cells if they captured the unexpected NBT. Cancel and resubmit jobs that are already stuck.
- Update both client and server, and back up saves before upgrading.
