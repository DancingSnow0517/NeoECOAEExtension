## 中文

Minecraft 1.20.1 / Forge，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。

### 修复

- 修复与 AdvancedAE 等 CPU 扩展共存时，加工产物已经进入 ME 网络，但 ECO 合成任务仍等待回收的问题。
- 修复远程机器界面的状态快照、客户端初始化与菜单切换，优先复用已加载的真实机器。
- 兼容旧版 LDLib 的供能优先级卡片绘制，避免打开大型工作站界面时报错。
- 补充纯流体界面的 EMI 悬停、配方及用途查询兼容。
- 修复样板预览滚动条崩溃，并改善物品管理菜单与机器定位高亮。
- 修复创造能源容量显示，完善创造与无限资源盘的过滤、存储隔离和接口搬运。
- 补充存储元件分区提示，并修正超大材料清单图片的生成与拼接。

### 新增与优化

- 新增轻量合成模式，贯通规划选项、合成确认和实际执行。
- 在正在运行的合成任务中显示实时合成图，同步节点完成状态和精确物料数量。
- 更新合成图明暗主题，优化递归层级布局、缩放、材料汇总及缓存分配。
- 完善合成清单和材料卡片，补充循环启动种子的提示与大数量图片导出。
- 更新大型工作站模型与动态配色，完善冷却控制、供能和相关配方。
- 改善多方块自动搭建的朝向、镜像及放置检查，并同步相关界面翻译和指南。

### 兼容性说明

- 请同步升级客户端和服务端。
- 本次包含 20.5.7 发布后的合成图、工作站、存储传输和界面改进。

## English

Minecraft 1.20.1 / Forge. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**.

### Fixed

- Fixed processing outputs entering the ME network while ECO crafting jobs kept waiting for their return when CPU extensions such as AdvancedAE were installed.
- Fixed remote machine UI snapshots, client initialization, and menu transitions, preferring the actual machine when it is already loaded.
- Made the power priority card rendering compatible with older LDLib versions to prevent errors when opening large workstation screens.
- Improved EMI hover, recipe, and usage queries in fluid-only interfaces.
- Fixed a pattern preview scrollbar crash and improved item action menus and machine location highlights.
- Fixed creative energy capacity display and improved filtering, storage isolation, and interface transfers for creative and infinite resource cells.
- Added storage cell partition tooltips and fixed generation and stitching of very large material list images.

### Added and improved

- Added lightweight crafting mode across planner options, crafting confirmation, and execution.
- Added live crafting graphs for running jobs with synchronized node completion and exact material quantities.
- Updated light and dark graph themes and improved recursive layouts, zoom, material summaries, and cache allocation.
- Improved crafting lists and material cards with cycle startup seed hints and large-quantity image exports.
- Updated large workstation models and dynamic colors and improved cooling controls, power handling, and related recipes.
- Improved orientation, mirroring, and placement checks during multiblock auto-building and updated UI translations and guides.

### Compatibility

- Update both client and server together.
- This release includes crafting graph, workstation, storage transfer, and UI improvements made after 20.5.7.
