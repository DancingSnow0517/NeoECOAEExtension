## 中文

这是 Minecraft 1.20.1 / Forge 的正式版。需要 Java 17，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。请同步升级客户端和服务端。

- 修复部分 LDLib 机器界面的 EMI 边界识别与拖放交互。
- 修复 AE2LT 过载样板供应器的自适应倍增，使用供应器自身的批量发配能力。
- 集成 AE2 合成计时，增强合成状态页交互，并在合成任务进入终态后停止刷新合成图。
- 支持存储与计算主机批量取放盘片，并减少终端库存枚举、无限域迁移和合成计划索引中的重复计算。
- 修复工作站智能冷却，移除工作站外壳配方中的存储组件需求，并重写计算与合成系统指南。
- 修复开发环境的数据生成事件订阅与运行依赖，并从发布 JAR 中移除 GTL 模型测试加载器。

---

## English

This is a stable release for Minecraft 1.20.1 / Forge. Java 17 is required. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**. Update clients and servers together.

- Fixed EMI bounds detection and drag-and-drop interactions in affected LDLib machine screens.
- Fixed adaptive scaling for the AE2LT Overload Pattern Provider by using its native batch dispatch.
- Integrated AE2 crafting timing, improved crafting status interactions, and stopped refreshing crafting graphs after jobs reach a terminal state.
- Added bulk cell insertion and removal to storage and computation hosts and reduced repeated work in terminal inventory enumeration, infinite-domain migration, and crafting plan indexing.
- Fixed workstation smart cooling, removed the storage component requirement from the workstation casing recipe, and rewrote the computation and crafting guides.
- Fixed development data-generation event registration and runtime dependencies, and removed the GTL model test loader from the release JAR.
