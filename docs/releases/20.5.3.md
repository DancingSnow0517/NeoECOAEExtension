## 中文

对比版本：`20.5.2`

适用版本：Minecraft 1.20.1 / Forge

**本次将大型集成工作站的运行配方固定为 1 tick，并引入 ECO 内置的大宗压缩存储：数字奇点物品矩阵接入大宗压缩，旧 MEGA 大宗矩阵转为弃用兼容。**

### 调整

- **大型集成工作站运行时每批配方固定为 1 tick**：JEI/EMI 仍展示配方原本的加工时间；实际运行吞吐由并行数量决定。
- **大宗压缩存储改为 ECO 内置实现**：压缩链由可逆的工作台配方自动识别（如铁粒、铁锭、铁块），不再依赖 MEGA Cells 的压缩功能；也可通过数据包 `data/<命名空间>/eco_compression/*.json` 添加或排除压缩关系。存储主机向网络提供虚拟的压缩/解压样板，产物先保存在盘内再回存网络。
- **大宗压缩迁移到 Bigger AE2 数字奇点物品矩阵**：默认 5 类资源，安装 ECO 大宗扩展卡后 25 类，数量无上限；悬浮提示显示类型用量与压缩状态。
- 旧 ECO 大宗存储矩阵（MEGA Cells）保留读取兼容并显示弃用提示，不再提供组装与拆解配方；ECO 大宗扩展卡改用 AE2 与 ECO 材料合成。

### 新增

- 存储主机中右键存储盘可打开操作菜单：大宗盘可预览并确认“标记并迁移”，每块盘可单独设置相对主机的优先级。
- 合成流体输入仓与输出仓新增稳定的流体处理器访问方法，供附属调用。

### 修复

- 数字奇点物品矩阵首次访问时自动迁移旧格式的精确库存，保留超出 long 范围的数量，重载后保持一致。
- 大宗标记查重覆盖全网所有大宗盘，迁移时不会从其他大宗矩阵抽取库存。
- 盘内仍有待回存的转换产物时不能拆解，避免产物丢失。

### 说明

- 1.20.1 暂未提供从存储主机远程打开元件工作台调整资源类型的功能。
- 旧的单类型 ECO 大宗物品存储矩阵（16M/64M/256M）保持原有存储方式，不参与压缩。

## English

Compared with: `20.5.2`

For Minecraft 1.20.1 / Forge

**This release fixes Large Integrated Workstation runtime recipes at 1 tick and introduces ECO's built-in bulk compression storage: the Digital Singularity Item Storage Matrix now uses bulk compression, and the old MEGA bulk matrix is deprecated with read compatibility.**

### Changed

- **Large Integrated Workstation runtime batches now take 1 tick**: JEI/EMI still show each recipe's original processing time; throughput is controlled by parallelism.
- **Bulk compression is now built into ECO**: compression chains are detected from reversible crafting recipes (for example iron nugget, ingot and block) without relying on MEGA Cells compression, and datapacks can add or exclude conversions in `data/<namespace>/eco_compression/*.json`. Storage hosts provide virtual compression/decompression patterns; outputs are held on the disk until the network accepts them.
- **Bulk compression moves to the Bigger AE2 Digital Singularity Item Storage Matrix**: 5 resource types by default, 25 with an ECO Bulk Expansion Card, with unlimited quantities. Tooltips show type usage and compression status.
- The old ECO Bulk Storage Matrix (MEGA Cells) keeps read compatibility with a deprecation notice and no longer has assembly or disassembly recipes. The ECO Bulk Expansion Card is now crafted from AE2 and ECO materials.

### Added

- Right-click a cell in the storage host to open its actions: bulk cells can preview and confirm "mark and migrate", and every cell can have its own priority relative to the host.
- Crafting fluid input and output hatches provide stable fluid handler accessors for addons.

### Fixed

- Digital Singularity Item Storage Matrices migrate old exact contents on first access, preserving amounts beyond the long range across reloads.
- Bulk marker duplicate checks cover every bulk cell in the network, and migration never extracts from another bulk matrix.
- Cells with conversion outputs still waiting for network storage can no longer be disassembled, preventing output loss.

### Notes

- 1.20.1 does not yet open the cell workbench remotely from the storage host to adjust resource types.
- The old single-type ECO Bulk Item Storage Matrices (16M/64M/256M) keep their existing storage and do not use compression.
