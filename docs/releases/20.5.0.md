## 中文

对比版本：`20.5.0-beta1`

适用版本：Minecraft 1.20.1 / Forge

**本次完善大型集成工作站的温控、加工时间与 AE/FE 供能，新增加工监控和步骤投料控制，优化大规模合成规划、合成图及附属兼容。**

### 新增

- **计算主机支持加工监控**：显示受支持 GT 机器与大型工作站的实际加工进度、时长、并行数及等待原因。
- **加工条目新增右键菜单**：支持定位样板供应器、打开供应器及受支持的加工机器界面，停止或恢复指定步骤的后续投料。
- **大型工作站支持独立加工时间与网络 FE 供能**：安装 Applied Flux 后可使用网络 FE，缺额按 AE2 当前换算配置由等价 AE 补足，保留配方的额外资源要求。
- **大型工作站新增温度机制与电预热**：按温区提高并行，支持主动冷却、过热锁定与凛冰恢复；可通过配置关闭温度机制，改用冷却液模式。
- **支持自动识别 GTM / GTL 制作路线**：根据已安装模组选择配方档案，调整主机、存储与大型工作站的阶段材料。
- **合成、存储、计算主机内置自动搭建窗口**：可直接设置长度、切换镜像并开始搭建。

### 改进

- **优化大型合成图浏览**：加入空间索引、渐进绘制与缓存，减少平移、缩放时的重复绘制，扩大完整依赖树的缩放范围。
- **优化复杂循环与备选路线规划**：减少重复物料溯源和外部供料计算，提前排除数量不足的路线；数量超出范围时保留可用的材料报告。
- **加快样板预览加载**：先同步布局与占用信息，再分批加载内容，已加载的样板可立即操作。
- **完善 JEI / EMI 支持**：兼容收藏导入与流体收藏，工作站配方统一展示耗能、加工时间、额外资源及适用升级卡。
- 减少终端库存扫描与精确数量同步开销，完善联动存储矩阵注册、配方及旧盘数据保留。
- 重整多方块预览、工作站任务卡与控制区布局，更新模型纹理、凛冰晶体动画及中英文指南。

### 修复

- 修复循环规划重复制造种子、放大中间材料需求的问题。
- 修复计算主机分页响应乱序、旧页面闪空及 CPU 详情页切换后空白的问题。
- 修复样板预览刷新后 Shift 连续取出错位、鼠标事件重复派发及滚动条显示异常的问题。
- 修复大型工作站未接入加工监控的问题；排队配方不会沿用当前配方进度，降档任务按实际分段显示。
- 修复缺少有效机器进度时仍显示空进度条的问题，保留进度不可用的文字提示。
- 修复 Cosmolite、GTLCore 及部分 AE2 附属共装时的规划菜单、CPU 选择与字段同步兼容问题。
- 修复 Xenon / Embeddium 下计算管道及存储盘体缺失，以及部分模型遮挡、发光和冷却液渲染问题。
- 完善 20.4.2 旧存储盘、无限域及玩家存储文件的读取与恢复处理。

### 调整

- 大型工作站新任务将加工时间与并行分开计算：基础配方时长最多为 200 tick，倍增样板同比增加加工时间与费用；已有任务保留原加工合同。
- 温度下降后，高并行任务可按最多 256 次一段继续加工，满足原档条件后恢复，保留材料、已付工作量与进度余数。
- 存储 IO 默认排除存储总线容器，并默认忽略创造存储输入，可在界面中调整。
- 结构终端保留物品，打开后提示使用对应主机 UI 内的搭建按钮。

## English

Compared with: `20.5.0-beta1`

For Minecraft 1.20.1 / Forge

**This release improves temperature control, processing times and AE/FE power for the Large Integrated Workstation, adds processing monitoring and per-step input control, and improves large crafting plans, graph rendering and addon compatibility.**

### Added

- **Processing monitoring in the Computation Controller**: view actual progress, duration, parallelism and waiting reasons for supported GT machines and Large Integrated Workstations.
- **Context menus for processing entries**: locate pattern providers, open provider and supported machine interfaces, and stop or resume further input dispatch for an individual processing step.
- **Independent processing times and network FE for the Large Integrated Workstation**: use FE stored in the ME network when Applied Flux is installed. Missing FE is covered by equivalent AE using the current AE2 conversion settings, while recipes retain their additional resource requirements.
- **Temperature control and electric preheating for the Large Integrated Workstation**: higher temperature tiers unlock greater parallelism, with active cooling, overheating protection and cryogenic recovery. A configuration option switches to coolant mode without temperature requirements.
- **Automatic GTM / GTL recipe profile selection**: select crafting progression based on installed mods, with updated progression materials for controllers, storage and the Large Integrated Workstation.
- **Built-in construction windows for crafting, storage and computation controllers**: set the structure length, toggle mirroring and start building from the controller interface.

### Improved

- **Large crafting graph navigation**: spatial indexing, progressive rendering and caching reduce repeated work while panning and zooming. A wider zoom range accommodates very large dependency trees.
- **Complex cyclic and alternative-route planning**: reduce repeated material tracing and external supply calculations, reject routes with insufficient quantities earlier, and retain usable material reports when quantities exceed the supported range.
- **Faster pattern preview loading**: synchronize layout and occupied slots first, then load contents in batches. Patterns become usable as soon as their contents arrive.
- **JEI / EMI integration**: support importing favorites, including fluid favorites, and consistently display workstation energy costs, processing times, additional resources and applicable upgrade cards.
- Reduce terminal inventory scanning and exact-quantity synchronization overhead, and improve integration storage matrix registration, recipes and legacy cell data preservation.
- Refine multiblock previews, workstation task cards and controls; update model textures, cryogenic crystal animations and the Chinese and English guides.

### Fixed

- Fix cyclic plans repeatedly producing seeds and overstating intermediate material requirements.
- Fix out-of-order pagination responses, briefly empty pages and blank CPU details after switching views in the Computation Controller.
- Fix misplaced repeated Shift extraction after pattern preview updates, duplicate mouse event dispatch and incorrect scrollbar rendering.
- Connect the Large Integrated Workstation to processing monitoring. Queued recipes no longer inherit the active recipe's progress, and downgraded batches report their actual segment progress.
- Hide progress bars when valid machine progress is unavailable while retaining the explanatory text.
- Fix planning menu, CPU selection and field synchronization compatibility with Cosmolite, GTLCore and certain AE2 addon combinations.
- Fix missing computation conduits and storage cell models with Xenon / Embeddium, along with several model occlusion, emissive rendering and coolant rendering issues.
- Improve reading and recovery of legacy 20.4.2 storage cells, infinite storage domains and player storage files.

### Changed

- New Large Integrated Workstation jobs calculate processing time separately from parallelism. Base recipe duration is capped at 200 ticks, and multiplied patterns scale processing time and costs proportionally. Existing jobs retain their original processing contracts.
- When temperature drops, high-parallelism jobs can continue in segments of up to 256 crafts and return to their original tier when its conditions are met. Materials, paid work and fractional progress are preserved.
- Storage IO excludes storage-bus containers and ignores creative storage inputs by default. Both settings can be changed in its interface.
- The Structure Terminal item remains available; opening it directs players to the construction button in the corresponding controller interface.
