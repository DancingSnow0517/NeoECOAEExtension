## 中文

这是 Minecraft 1.20.1 / Forge 的 Beta 版。需要 Java 17，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。请同步升级客户端和服务端。

- 修复部分 LDLib 机器界面在 EMI 中的边界识别，避免配方列表覆盖界面。
- 修复 AE2LT 过载样板供应器的自适应倍增，使用供应器自身的批量发配能力。
- 合成任务进入终态后停止刷新合成图，并精简合成确认与存储优先级界面的同步逻辑。
- 统一存储与计算驱动器界面的盘片取放逻辑，减少终端库存枚举、无限域迁移和合成计划索引中的重复计算。
- 修复开发环境的数据生成事件订阅与运行依赖，并从发布 JAR 中移除 GTL 模型测试加载器。

---

## English

This is a beta for Minecraft 1.20.1 / Forge. Java 17 is required. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**. Update clients and servers together.

- Fixed EMI bounds detection for some LDLib machine screens so the recipe list does not cover them.
- Fixed adaptive scaling for the AE2LT Overload Pattern Provider by using its native batch dispatch.
- Stopped refreshing crafting graphs after jobs reach a terminal state and simplified synchronization for the crafting confirmation and storage priority screens.
- Unified cell insertion and removal in storage and computation drive screens and reduced repeated work in terminal inventory enumeration, infinite-domain migration, and crafting plan indexing.
- Fixed development data-generation event registration and runtime dependencies, and removed the GTL model test loader from the release JAR.
