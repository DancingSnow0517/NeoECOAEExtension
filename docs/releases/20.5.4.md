## 中文

对比版本：`20.5.3`

适用版本：Minecraft 1.20.1 / Forge

**本次发布 20.5.4，修复计算子系统通讯接口过滤槽交互导致的物品复制与不可堆叠物品异常叠加，并补充新版 JEI 与 ExtendedAE Plus 的兼容修复。**

### 修复

- 修复计算子系统通讯接口过滤槽在点击、拖拽操作中可能复制物品的问题。
- 修复过滤槽放入不可堆叠物品时数量异常叠加的问题。
- 修复新版 JEI 配方布局高度 Mixin 校验失败及书签接口改名后的兼容问题。
- 修复 ExtendedAE Plus 虚拟合成卡缓存升级槽状态的问题，改为实时读取升级槽，兼容较早的 EAEP 1.6.3 版本。

## English

Compared with: `20.5.3`

For Minecraft 1.20.1 / Forge

**Version 20.5.4 fixes item duplication and invalid stacking caused by computation subsystem interface filter-slot interactions, and adds compatibility fixes for newer JEI and ExtendedAE Plus versions.**

### Fixed

- Fix item duplication in computation subsystem interface filter slots during clicks and drags.
- Fix invalid quantity stacking when inserting non-stackable items into filter slots.
- Fix compatibility with newer JEI recipe-layout Mixin validation and renamed bookmark APIs.
- Make the ExtendedAE Plus virtual crafting card read upgrade slots in real time, preserving compatibility with older EAEP 1.6.3 versions.
