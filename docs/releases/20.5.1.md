## 中文

对比版本：`20.5.0`

适用版本：Minecraft 1.20.1 / Forge

**本次主要修复专用服务器启动问题，以及 GTLCore、MAE2 环境下的兼容性与加工投料问题，并按已安装附属注册大型工作站升级卡。**

### 修复

- 修复凛冰粉与天外寒冰配方使用空的陨石粉标签，导致无法合成的问题。
- 修复远程机器界面错误加载客户端类，导致专用服务器初始化崩溃的问题。
- 修复与 GTLCore、MAE2 共装时，样板供应器注入冲突导致的启动崩溃。
- 修复 ECO 智能翻倍受到 GTL 自动倍增开关及供应器批量策略限制的问题，由 ECO 独立控制加工批次。
- 完善 GT 加工投料：保留原生样板缓冲仓容量限制，编程电路每批仅发送一次；批次被拒绝后自动缩小重试并退回未使用资源。

- 修复 1.20.1 掉落表精准采集条件格式错误，恢复盈能水晶簇正常掉落盈能水晶。
### 调整

- 大型工作站附属升级卡仅在安装对应附属模组时注册，空白升级卡始终保留。

## English

Compared with: `20.5.0`

For Minecraft 1.20.1 / Forge

**This release fixes dedicated server startup, compatibility and processing input dispatch with GTLCore and MAE2, and registers Large Integrated Workstation addon upgrade cards only when their corresponding mods are installed.**

### Fixed

- Fix the empty Sky Stone Dust tag preventing Cryotheum and Cryotheum Crystal from being crafted.
- Fix dedicated server initialization crashing when the remote machine interface loads client-only classes.
- Fix a pattern provider Mixin conflict causing startup crashes when used with GTLCore and MAE2.
- Fix ECO smart batch scaling being restricted by GTL's auto-expand setting and provider batch policies. ECO now controls its own processing batch sizes.
- Improve GT processing input dispatch: preserve native pattern buffer capacity checks and send programmed circuits only once per batch. Rejected batches are retried at a smaller size, with unused resources returned.
- Fix 1.20.1 loot table Silk Touch predicates so Energized Crystal Clusters correctly drop Energized Crystals.

### Changed

- Register Large Integrated Workstation addon upgrade cards only when the corresponding addon is installed. The blank upgrade card remains available in all installations.
