## 中文

这是 Minecraft 1.20.1 / Forge 的正式版。需要 Java 17，建议使用 **AE2 15.4.11、LDLib 1.0.52.a 和 GuideME 20.1.15**。请同步升级客户端和服务端。

- 为万象构序新版提供批量与精确派发 API，支持分子设备和矩阵注册供应器适配器。
- 为外部 CPU 提供大单接纳、保存恢复、取消及精确产物回投 API。只有实际接管派发的 CPU 才会跳过 ECO 的默认派发逻辑。
- 万象构序联动需要使用已迁移到此 API 的版本。

---

## English

This is a stable release for Minecraft 1.20.1 / Forge. Java 17 is required. Recommended versions: **AE2 15.4.11, LDLib 1.0.52.a, and GuideME 20.1.15**. Update clients and servers together.

- Added batch and exact dispatch APIs for OmniSequence to register adapters for molecular machines and assembler matrices.
- Added external CPU APIs for big-order admission, save and restore, cancellation, and exact output routing. Only CPUs that take ownership of dispatch bypass ECO's default dispatch logic.
- OmniSequence integration requires a build that uses the new API.
