## 中文

对比版本：`20.5.4`

适用版本：Minecraft 1.20.1 / Forge

**本次为 20.5.5 Beta 测试版，包含合成规划与批量发配修复、统计卡片界面和 GT 配方补全。**

- 修复 JEI 初始化多方块配方时，为确定材料槽位数量而生成最大长度虚拟结构，导致超大长度配置下内存耗尽的问题。
- 材料统计改为不创建虚拟世界、不保存方块位置；JEI 材料转移及 EMI 材料查询使用相同统计路径。
- 多方块预览最多显示 32 段扩展（总长度 36），防止右键循环到超大长度时卡死或崩溃；实际结构检查和自动搭建继续遵循服务器原有配置上限。
- 配置长度上限降低后，已有预览在重建时自动收缩到有效范围；材料槽对象保持稳定。
- 包含 CPU 状态界面待合成数量一次汇总优化，避免逐项重复扫描全部合成任务。
- 合成规划保留首个可完成的配方路线，仅在材料不足时搜索备用组合，循环开关关闭时也支持路线回退。
- 移除已停用的普通大宗盘外壳配方，解决其与流体外壳配方完全相同的冲突；清理旧大宗盘配方生成逻辑，避免数据生成时恢复已删除的配方。
- 修复循环合成中的保种、副产物生产路线和材料平衡判断，优先保留普通规划结果，并增加合成规划诊断导出。
- 修复智能翻倍样板跨实例匹配不一致导致批量发配退化的问题。
- 补齐 GT 材料加工、充能水晶粉与充能福鲁伊克斯水晶粉、超导处理器配方，兼容旧版与新版 GT 配方格式。
- 合成控制器并行与队列、FX / FT、无限模式条件、计算主机统计、CPU 列表及合成状态悬停提示改为统计卡片；精简卡片尺寸，并支持在 CPU 提示中按住 Shift 查看精确值。
- 合成状态进度改用整格显示，过滤短周期同步计数，修正控制器与工作站标题、提示和多语言文本。
- 交换网络及无限模式批次统一按 1 tick 执行，同步工作核心、控制器耗时显示和中英文指南。
- 修复存储盘类型灯与等级灯的共面闪烁，以及计算主机卡片在客户端窗口缺失时读取 Shift 状态的异常。

## English

Compared with: `20.5.4`

For Minecraft 1.20.1 / Forge

**This 20.5.5 Beta includes crafting planner and batch dispatch fixes, statistics cards, and additional GT recipes.**

- Fix memory exhaustion during JEI multiblock recipe registration when a very large structure length limit caused the entire maximum-size preview to be generated just to count material slot types.
- Collect materials without creating a dummy world or retaining block positions, including JEI recipe transfer and EMI material queries.
- Limit visual previews to 32 repeating sections (36 blocks total) while preserving configured limits for real structures and automatic building.
- Clamp existing previews when the configured maximum is reduced, retaining stable material slot widgets.
- Include the CPU status pending-output aggregation optimization to avoid rescanning all crafting tasks for every item.
- Preserve the first viable crafting route and search alternatives only when supplies are insufficient, including when cycle planning is disabled.
- Remove the retired standard bulk-cell housing recipe that conflicts with the fluid housing recipe, and stop datagen from restoring removed legacy bulk-cell recipes.
- Fix seed preservation, byproduct production routes, and material balance checks in cycle crafting; prefer ordinary planning results and add crafting plan diagnostic exports.
- Fix inconsistent matching between smart-doubling pattern instances that degraded batch dispatch.
- Complete GT material processing, energized crystal and energized fluix crystal dust, and superconducting processor recipes for both older and newer GT recipe formats.
- Introduce statistics cards for crafting parallelism and queues, FX / FT, unlimited-mode requirements, computation hosts, CPU lists, and crafting status tooltips; reduce card sizes and support holding Shift for exact CPU values.
- Show crafting progress in whole operations, filter transient synchronization counts, and correct controller and workstation titles, tooltips, and translations.
- Execute exchange-network and unlimited-mode batches in one tick, with matching worker and controller timing displays and updated English and Chinese guides.
- Fix flickering between storage-cell type and tier lights, and a Shift-state lookup error when computation host cards render without a client window.
