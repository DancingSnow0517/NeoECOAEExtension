# 样板标准接口与特殊能力改造

适用：Minecraft 1.21.1 / NeoForge。源码与验证日期：2026-10-16。

## 基础契约

普通样板只实现 AE2 `IPatternDetails` 即可，不需要 ECO 基类或注册。规划使用原样板的输入、倍率、产物、返还物和 AEKey 组件身份；首选输入参与递归合成，其余替代物遵循库存与 `IInput.isValid`。哪些产物能启动配方由合成服务公布，副产物仍参与物资记账。忽略组件的规划选项不能覆盖样板自身的输入拒绝。

普通发配继续将原始样板交给 AE2 供应器。批量拒绝后的单次回退、物资事务、能量退款与不确定接收状态的处理沿用现有执行机制。实现标准样板接口本身不会授权直接生成产物或虚拟合成。

## 扩展边界

| 能力 | 公开入口 | 未注册时 |
| --- | --- | --- |
| 动态匹配、动态产物、额外执行限制 | `ECOPatternSemanticsRegistry` / `ECOPatternSemanticAdapter` | 通用 AE2 解析 |
| 经具体验证的装配器快速执行 | `ECOExecutionOptimizationRegistry` | 普通执行 |
| 包装样板的供应器身份委托 | `ECOPatternWrappers` | 保留原始实例 |

接口位于 `cn.dancingsnow.neoecoae.api.me.pattern`。语义 DTO 使用不可变列表、精确 `BigInteger` 输入/反馈数量及 AE2 `GenericStack` 产物，不暴露规划图或内部数量类型。适配器不得替换物理样板实例。

注册在通用初始化时完成。ID 唯一，高优先级先匹配，同级按 ID 字典序；语义及执行能力匹配首项生效。适配器异常不得静默落入宽泛授权。具体接入示例见 [API 指南第 8 节](API_ZH_CN.md#8-样板导入与容器所有权)。

Useless 与 Thunderbolt 的特殊语义现在通过同一公开 API 注册；EAEP 原先仅委托通用解析的适配器已删除。规划器移除了针对 Useless 的输入接受判断，统一使用 `IInput.isValid`。包装器不再猜测方法名，Thunderbolt 在兼容模块显式注册已确认的供应器查找与包装接口。

AE2 三类内置装配样板的快速执行保证由 AE2 兼容模块注册。净增殖验证依据通用语义与确定性证明，保留单一精确候选、耐久与未知返还物限制。循环规划仍须通过数量平衡和实际执行顺序验证。

## 缓存与失败处理

语义或执行能力的注册变化、配方重载均更新契约代次。编译结构、会话内结构、阶段语义与执行优化凭证不能跨代复用。长寿命编译器每次编译取得注册快照；计算中契约变化会安全失败，调用方需重新计算。阶段缓存同时检查物理实例，避免把重建样板替换成缓存中的旧实例。

执行缓存的清理与访问已同步，旧提取结果、撤销前凭证及清理后迟到签发的旧代凭证均不可继续授权。调度构造也明确拒绝不支持的语义，不能回退到原始主产物掩盖特殊适配失败。
